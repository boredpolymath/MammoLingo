# Solo Usability Protocol

MammoLingo is maintained by a solo developer and currently has no representative-user panel. This protocol provides repeatable self-testing but does not replace moderated usability testing with intended users.

Before each release, Bored Polymath Studios will test:

1. Find a known term from Home using keyboard and touch.
2. Find a term through Browse and clear the search.
3. Open an explanation, read the educational-limit notice, open the source link, and return.
4. Save a term, confirm the count and Saved screen, then remove it and clear all saved terms.
5. Repeat the flow at 320px, common phone width, tablet width, and desktop width.
6. Test without storage, offline after initial load, and with a pending service-worker update.
7. Check that the app never asks for report text or personal information and does not imply diagnosis or individual recommendations.

Record the date, browser/device, completed steps, defects, and follow-up changes in the release sign-off record.
